Για τον έλεγχο του Flutter project χρησιμοποιούνται δύο αρχεία:

- `FlutterReview.md`
- `FlutterReviewCommon.md`

Στο `FlutterReview.md` εμφανίζονται οι screens, τα layouts και τα βασικά sections της εφαρμογής με τη σειρά που ελέγχθηκαν.

Κάτω από κάθε section υπάρχει λίστα με αριθμούς που τα βρίσκουμε στο FlutterReviewCommon.md , για παράδειγμα:

```text
Common:
6) SectionTitle
7) ActionCard
15) ReportsProvider

```
Τα αρχεία που αφορούν την εφαρμογή βρίσκονται στον φάκελο "lib".
