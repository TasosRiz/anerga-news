## 1. AuthApi

Αναλαμβάνει:

- τη διαχείριση των authentication requests
- το login
- το register
- τη φόρτωση του συνδεδεμένου χρήστη
- το logout
- την επικοινωνία με το Laravel API
- τη διαχείριση authentication errors

Χρησιμοποιεί:

- 3) AuthStorage
- 11) ApiConfig
