## Project Review


Για τον έλεγχο του React project χρησιμοποιούνται δύο αρχεία:

- `ProjectReview.md`
- `ProjectReviewCommon.md`

Στο `ProjectReview.md` εμφανίζονται οι σελίδες και τα βασικά sections του project με τη σειρά που ελέγχθηκαν.

Κάτω από κάθε section υπάρχει λίστα με αριθμούς, για παράδειγμα:

```text
Common:
1) AppStatus
5) PagesLayout
7) SidePanel

Οι αριθμοί αυτοί αντιστοιχούν στα reusable components και hooks που περιγράφονται αναλυτικά στο ProjectReviewCommon.md.

```
Τα αρχεία που αφορούν το sote βρίσκονται στον φάκελο "src".
